# models/final_int8/ — the deployed model bundle

The single supported model (GEN-2). Generated by `training/kaggle/nb07_final`
from SisFall + KFall + FallAllD windows (UMAFall excluded — its pocket
smartphone logs no gyroscope; see `datasets/README.md`).

| File | What it is |
|---|---|
| `model.tflite` | INT8 model, **23,080 bytes (22.54 KB)**, 7,947 params, sha256 `8e7cb13067fca18a…` |
| `model.h` | same as a C array for firmware (`g_model`, `g_model_len`); header records the preprocess signature `2574e6104c95` |
| `final_model_card.md` | the operating-point sweep on 814 held-out fall trials + recommended operating point (threshold 0.7, k=4) |
| `quantisation_report.json` | FP32 F1 0.7109 → INT8 F1 0.7138, agreement 0.9944, arena estimate 8,208 B |
| `quantisation_comparison.{json,csv}` | why instance norm lives in the pipeline (in-graph collapses under INT8) |
| `norm_constants.h` / `norm_constants.json` | global 6-channel mean/std from train subjects — **a record, not used by the final firmware** |

## Contract (must hold wherever this model is used)

- Input: 100×6 window at 50 Hz, g and deg/s, channels `ax ay az gx gy gz`.
- **Per-window instance normalisation in float** (mean, std + 1e-6, per
  channel, per window) applied by the *caller* before quantisation — the
  Python equivalent is `fdlib.preprocess.instance_normalise`.
- Quantise with the tensor's own input scale/zero-point; dequantise output
  (3 classes: bkg, alert, fall).
- Operate on `p_alarm = p_alert + p_fall` with threshold + *k*-consecutive
  confirmation. Model-card recommended: 0.7 / 4; firmware default: 0.95 / 2.

## Verified status

- Desktop (Kaggle): FP32↔INT8 agreement 0.9944 on held-out subjects.
- Desktop (this repo): fires correctly on the KFall S06T20R01 replay through
  the exact firmware preprocessing — `results/replay_verification/`.
- Device: runs on the physical ESP32 build (boot + inference + alarm verified
  functionally); latency/RAM high-water PENDING

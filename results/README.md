# results/

All quantitative evidence, in three tiers. The per-number audit is
`docs/RESULTS_PROVENANCE.md`.

## `kaggle_reference/` — measured on real datasets

Every CSV/JSON/figure pulled back from the Kaggle runs of the `training/`
pipeline (GEN-2). These are the numbers behind Tables I–IV.

- `results_e1.csv` (+ summary) — within-dataset baselines, SisFall post-fall
- `results_e1_preimpact.csv` — baselines on the pre-impact task, KFall
- `results_e2.csv` — leave-one-dataset-out × adaptation ladder
- `results_e3.csv`, `e3_operating_points.csv`, `e3_lead_times_windows.csv` —
  pre-impact lead time and false alarms (2,346 KFall trials)
- `results_e5.csv` — ablations (window, rate, channels, placement)
- `quantisation_report.json`, `quantisation_comparison.json/.csv` — E4
- `final_model_card.md`, `final_operating_points.csv` — deployed model +
  operating-point sweep (the numbers behind the paper's deployed-model rows)
- `trial_level_eval.{csv,md}`, `debounce_analysis.{csv,md}` — Yu-protocol
  trial-level scoring and the lead-vs-false-alarm trade-off
- `table_{I,Ib,II,III,IV,ablations}.{csv,md}` — assembled tables
- `fig_*.png` — paper figures
- `gate_report.json`, `nb00_probe_report.md`, `nb00_probe_verdict.json`,
  `nb01_report.md` — dataset reality checks and preprocessing gates
- `norm_constants.json` — 6-channel mean/std fitted on train subjects
  (200,596 windows; a record only — firmware does per-window norm)
- `fdlib_version.json`, `experiment_log.csv` — code-version hash and the
  per-kernel run log (dates, commits, states)
- `hardware_measurements.json` — the pending template (nulls)
- `on_device_trials.md` — trials protocol, unfilled

## `tables/` — paper-ready markdown tables

Copies of the assembled tables for direct inclusion:
`table_I.md`, `table_Ib.md`, `table_II.md`, `table_III.md`, `table_IV.md`,
`table_ablations.md`, `trial_level_eval.md`, `debounce_analysis.md`.
`table_IV.md` marks latency/RAM/battery cells `PENDING-HW` — keep them that
way until the bench run exists.

## `replay_verification/` — this repository's own numbers

Desktop verification that the committed INT8 model + firmware preprocessing
detect a real fall trial (KFall S06T20R01), at six operating points, plus a
legacy-model cross-check. Generated by `tools/replay_desktop_check.py`;
see `REPLAY_VERIFICATION.md` inside.

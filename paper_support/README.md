# paper_support/

Everything needed to draft, verify and typeset the conference paper.
Discipline: a number enters a manuscript only if it exists in a committed
artifact (or is explicitly `PENDING`). The audit habit is documented in
`manuscript/VERIFICATION.md` — three numbering errors were caught and fixed
there by tracing every claim to its file.

## Contents

- `manuscript/ieee/` — IEEEtran draft source: `main.tex`, `refs.bib`,
  `fig_method.png`, `fig_lead_time.png`, `fig_sanity_traces.png`,
  `fig_method.tex`, `ieee.csl`. Build with `tectonic -X compile main.tex`
  (stock pdfLaTeX + IEEEtran also works).
- `manuscript/OUTLINE.md` — section-by-section plan, venue targets.
- `Fall_Detection_Experimental_Plan_v2.pdf` — the experimental plan the
  pipeline implements.
- `figures/` — pre-impact lead-time distribution, sanity traces, KFall alert
  intervals, system diagram (copies of the figures in `results/kaggle_reference/`).
- `tables/` — paper-ready tables assembled for this repo:
  - `dataset_summary.md` (datasets/trials/subjects/roles)
  - `model_operating_points.md` (the deployed model's trial-level sweep)
  - `hardware_resources.md` (Table IV with `PENDING-HW` cells, as-is)
  - main result tables live in `results/tables/` (I, Ib, II, III, ablations).
- `checklists/` — submission checklist + method reproducibility checklist.
- `refs.bib` — all dataset and method citations.

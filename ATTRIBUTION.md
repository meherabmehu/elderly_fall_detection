# Attribution and provenance

This repository consolidates work from two coordinated project lines. It is
published for a conference submission by the elderly fall detection team; the
content origins are recorded here so that authorship stays traceable.

## Components and origins

| Component | Origin | License/terms |
|---|---|---|
| `training/` (fdlib library, nb00–nb07 notebooks, scripts, Makefile, PROJECT_PLAN.md, SHOWCASE.md) | Reference repository [`arifshekhk8/preimpact-fall-detection-tinyml`](https://github.com/arifshekhk8/preimpact-fall-detection-tinyml) (team co-author) | used with permission within the project team |
| `results/kaggle_reference/` (CSVs, JSON, figures, reports) | Kaggle runs of the above pipeline (run log included) | same |
| `models/final_int8/` | Generated by the above pipeline (nb07 export) | same |
| `firmware/fall_detector_core2x/`, `firmware/MEASUREMENT.md` | Reference repository firmware | same |
| `firmware/esp32_ai_final_live_deployment/`, `esp32_ai_final_millis_sampling/`, bring-up and AI-free sketches, `hardware/`, `reports/`, `presentations/` | This project's hardware work (ESP32 build, Dhaka) | project team |
| `wokwi/final_model/src/main.cpp` | New in this repository: merges the verified final firmware with the KFall replay (REPLAY_MODE), with a TFLM library-compat shim | project team |
| `tools/` and `results/replay_verification/` | New in this repository | project team |
| `docs/` (except `PROJECT_HANDOFF_SUMMARY.md`) | New in this repository | project team |
| `legacy/` | This project's earlier synthetic-pipeline snapshot | project team |
| `paper_support/` | Manuscript draft + plan from the reference repository; checklists/tables assembled here | same as training/ |

## Dataset obligations

SisFall (Sucerquia et al. 2017), SisFall Enhanced annotations (Musci et al.
2018/2020), KFall (Yu et al. 2021), FallAllD (Saleh et al. 2020), UMAFall
(Casilari et al. 2017). BibTeX in `paper_support/refs.bib`. **Raw KFall data
must not be redistributed.**

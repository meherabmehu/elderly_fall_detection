# Dataset acquisition

Raw datasets are intentionally not stored in this repository.

- SisFall Enhanced: https://www.kaggle.com/datasets/nvnikhil0001/sisfall-enhanced/data
- KFall: https://sites.google.com/view/kfalldataset/home
- FallAllD: https://ieee-dataport.org/open-access/fallalld-comprehensive-dataset-human-falls-and-activities-daily-living
- UMAFall: https://figshare.com/articles/dataset/UMA_ADL_FALL_Dataset_zip/4214283

Expected local/Kaggle roots:

```text
SisFall/
KFall/KFall Dataset/KFall Dataset/sensor_data/
FallAllD__zip/FallAllD/
UMAFall/
```

Use the original papers and dataset pages for citations. Never commit raw KFall files or private access material.
